RJ Dev Studio

RJ Dev Studio is an India-based independent app studio creating focused, respectful, privacy-conscious mobile experiences for everyday routines.

Primary product

Jaap Counter is RJ Dev Studio's first public app, built for Hindu devotional mantra counting on Android. It is designed as a calm digital mala for japs, goals, streaks, practice time, meditation, local backup, and optional private Google Drive backup.
